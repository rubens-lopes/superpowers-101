## Prompt (verbatim)

> We were tasked with creating a brief (5-10min) presentation about the superpowers plugin (https://github.com/obra/superpowers). It should include a bit of hands-on. So my idea is to use it (superpowers) to build the presentation itself, resulting in a GitHub Page backed but it's on repository that people can dig to learn more. I'd lean toward Astro to keep things simple and focused.
> The repo must include all prompts (include this one), specs, plans and other docs used during this process. The presentation itself can have a summary or most relevant ones.
>
> I'm seeing 4 slides or so:
>
> 1. What is it and where to learn more
> 2. What is inside (workflow, skills, philosophy)
> 3. The Good and the Not So Good
> 4. Hands On (maybe a new feature or a refactor)

## Outcome

The brainstorming skill drove a Q&A (one question at a time). Decisions made:

- **Audience:** devs already using Claude Code, possibly PMs/POs present.
- **Slide format:** custom full-screen Astro sections, no slide framework.
- **Hands-on:** live demo on this repo, with a repo-history walkthrough as backup.
- **Slide 3:** user's own experience, structured by Claude; placeholder until draft review.
- **Repo:** new `<owner>/superpowers-101`.
- **Artifact capture:** curated markdown with verbatim prompts (this file is the first).
